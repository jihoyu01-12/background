# 배경 그라데이션 생성기

두 가지 색상을 선택해 페이지의 선형 그라데이션 배경을 미리 보고, 적용된 CSS 값을 확인할 수 있는 간단한 웹 페이지입니다.

## 실행 방법

별도의 설치나 빌드 과정이 필요하지 않습니다.

1. 저장소에서 `index.html` 파일을 찾습니다.
2. 파일을 웹 브라우저에서 엽니다.
3. 색상 선택기를 변경해 그라데이션을 확인합니다.

## 사용 기술

- HTML
- CSS
- JavaScript

## 파일 구성

- `index.html` — 페이지 구조와 색상 선택기
- `style.css` — 페이지 및 요소 스타일
- `app.js` — 선택한 색상을 배경 그라데이션에 적용하고 CSS 값을 표시하는 동작

## 사용 방법

두 색상 선택기에서 원하는 색을 고르면 배경이 왼쪽에서 오른쪽 방향의 선형 그라데이션으로 갱신됩니다. `Current CSS Background` 아래에서 적용된 CSS 값을 확인할 수 있습니다.
